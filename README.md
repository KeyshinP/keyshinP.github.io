# Keyshin's Blog

Personal tech blog & engineering documentation built with [Astro](https://astro.build/).

## Features
- **Modern Fluid Typography & Responsive Layout**: Optimized readability across devices with adaptive type scaling.
- **Dark / Light Mode**: Auto-detects system preferences with local storage override and zero-FOUC script.
- **Reading Progress Bar**: Dynamic top-fixed indicator for article depth.
- **Syntax Highlighting & Copy Button**: Powered by Shiki with dual themes and one-click code copy.
- **Responsive Table of Contents (TOC)**: Sticky sidebar with real-time `IntersectionObserver` scrollspy.
- **Automated CI/CD**: Seamless build and deployment to GitHub Pages via GitHub Actions.

## Getting Started

```bash
# Install dependencies
pnpm install

# Start local dev server
pnpm dev

# Build for production
pnpm build

# Preview build locally
pnpm preview
```
